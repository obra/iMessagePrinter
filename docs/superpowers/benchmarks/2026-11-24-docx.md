# DOCX export benchmark — 2026-11-24

Baseline for the first correct DOCX implementation, before optimization.

## Command

```
IMESSAGEPRINTER_BENCHMARK=1 swift test --filter DocxBenchmarkTests
```

The test is gated on `IMESSAGEPRINTER_BENCHMARK=1`; without it the benchmark is skipped.
Timings cover planning, rendering, image preparation, and packaging. They exclude the
Swift build and test startup.

## Environment

- Machine: Apple M5 Max, macOS 27.0
- Swift: 6.4.2 (debug test build)
- Data: the largest conversation by message count in `~/Library/Messages/chat.db`
- Messages: 10,885
- Exportable image attachments: 750

## Results

| Image mode | Seconds | Output bytes |
| --- | ---: | ---: |
| Omit (`mode=0`) | 0.44 | 343,220 |
| Thumbnail (`mode=1`) | 82.99 | 66,497,314 |
| Full resolution (`mode=2`) | 45.39 | 1,304,785,786 |

Full resolution copies original PNG/JPEG bytes, so it is faster than thumbnail mode, which
re-encodes all 750 images to JPEG. It also produces a 1.3 GB document, which is the main
size problem the optimization task targets.
