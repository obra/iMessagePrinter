# DOCX export benchmark — 2026-11-24

Baseline for the first correct DOCX implementation, before optimization.

## Command

```
IMESSAGEPRINTER_BENCHMARK=1 swift test --filter DocxBenchmarkTests
```

The test is gated on `IMESSAGEPRINTER_BENCHMARK=1`; without it the benchmark is skipped.
Timings cover planning, rendering, image preparation, and packaging. They exclude the
Swift build and test startup.

## Environment

- Machine: Apple M5 Max, macOS 27.0
- Swift: 6.4.2 (debug test build)
- Data: the largest conversation by message count in `~/Library/Messages/chat.db`
- Messages: 10,885
- Exportable image attachments: 750

## Results

| Image mode | Seconds | Output bytes |
| --- | ---: | ---: |
| Omit (`mode=0`) | 0.44 | 343,220 |
| Thumbnail (`mode=1`) | 82.99 | 66,497,314 |
| Full resolution (`mode=2`) | 45.39 | 1,304,785,786 |

Full resolution copies original PNG/JPEG bytes, so it is faster than thumbnail mode, which
re-encodes all 750 images to JPEG. It also produces a 1.3 GB document, which is the main
size problem the optimization task targets.

## After optimization

Same command, machine, and conversation (10,885 messages, 750 exportable images). Changes:
one bulk attachment query per conversation instead of one per message, parallel image
preparation, and stored (uncompressed) ZIP entries.

| Image mode | Seconds | Output bytes |
| --- | ---: | ---: |
| Omit (`mode=0`) | 0.29 | 3,508,756 |
| Thumbnail (`mode=1`) | 16.10 | 71,823,853 |
| Full resolution (`mode=2`) | 6.33 | 1,320,344,825 |

Speedup: omit 1.5x, thumbnail 5.2x, full resolution 7.2x.

Storing ZIP entries makes the document larger: the small omit-mode file grows from 343 KB
to 3.5 MB because its XML is no longer deflated. The image-heavy modes barely change in
size because their payload is already-compressed image data. Full resolution is still a
1.3 GB document; the optimization targeted time, not size.

## Manual acceptance artifact

To write a thumbnail-mode DOCX from the same real conversation and inspect it outside the
test process:

```
IMESSAGEPRINTER_ACCEPTANCE_DIR=/tmp/imessage-acceptance \
  swift test --filter DocxBenchmarkTests/testWritesManualAcceptanceDocx
```

The test prints the output path and leaves the file in place.
